    Interactions

    Drag and pet are on by default; password peeking and scroll reactions are opt-in.

    Agent list

    Compact bots in rows, one per form, the way a chat app lists agents, in the colorway above.

    Preview
    4 s

    Lifecycle

    IdleRests and blinks. Hover gives a small squish (or call nudge() from the row).
    SentSetting state="working" hops once. Your row moves to the top and reads “Working…”.
    WorkingRocks and churns; eyes become three thinking dots. Loops until the state changes.
    Donestate="done" pops and squints, then rests. Your row shows the reply preview as unread.
    ReadSet state="idle" when the reply is opened. No animation.

    Reduced motion: no hop, rock or pop; the dots stay still and the squint still shows. A compact bot never shows text, so always pair it with visible state text.

            Colours and theming
            
    The bot reads the site's semantic tokens, so with tokens.css loaded it follows light, dark and system themes on its own. Override any of these on the element or an ancestor:
    
            
    exa-bot {
  --exabot-accent: var(--color-accent);
  --exabot-focus: var(--color-focus);
  --exabot-bubble-surface: var(--color-surface-raised);
  --exabot-bubble-text: var(--color-text-primary);
  --exabot-bubble-border: var(--color-border);
  --exabot-bubble-shadow: var(--elevation-md);
  --exabot-font: var(--font-family-base);
  --exabot-heart: #ec4899;
}
    
          
    
          
    
            Calling it from the page
            
    const bot = document.querySelector('exa-bot');
bot.say('Welcome back');
bot.celebrate();           // e.g. after a form submits
bot.confused('Page not found');
bot.state = 'working';     // agent states: idle | working | done
// also: poke(), hop(), dizzy(), peek(true|false),
//       stretch(), sleep(), wake(), nudge()
bot.addEventListener('exabot-poke', e => console.log(e.detail.line));
// also: exabot-dizzy, -celebrate, -confused, -peek,
//       -fling, -pet, -state {state, from}
