# Platform icons

First-party marks for Exaforce platform capabilities: things we built, drawn
once here and never substituted with a lookalike. Interfaces (console, studio,
mcp, api), Exabots (exabot-detect/-triage/-investigate/-hunt/-respond), the
three models (semantic, behavioral, knowledge) and the data platform
(data-warehouse, etl, in-memory-database).

Drawing rules, so the set stays coherent as it grows: 24-unit artboard,
1.5-unit strokes converted to paths, 2-unit live-area padding, `fill="currentColor"`,
no `width`/`height`, no `<title>`. Monochrome: the accent is applied by the
context that renders it. Must read at 20px; within a group, share a structural
motif. Filenames are the slugs above; the styleguide picks up new files with
no code change.
